# HPC USE Trainer

An interactive, self-contained study trainer for the **USE — Use of the HPC Environment**
branch of the [HPC Certification Forum](https://www.hpc-certification.org/) skill tree
(modules **USE1–USE7**).

It is a single `index.html` file with **no dependencies** — plain HTML, CSS, and
JavaScript. No build step, no frameworks, no network calls. Your progress is saved
locally in your browser (`localStorage`).

## Use it

- **Online:** published via GitHub Pages (see the repository's Pages URL).
- **Locally:** just open `index.html` in any modern browser.

## What's covered

**USE1 · Cluster Operating System** (8 subskills): command line interface, shell
scripts, the UNIX file system tree, remote access (SSH), the software environment
(modules), CLI editors, terminal multiplexers, and background processes & signals.

**USE2–USE7:** running parallel programs (SLURM/TORQUE), building parallel programs
(compilers, linking, build systems), developing parallel programs (MPI/OpenMP,
races & deadlocks), automating common tasks (cron, scripting), workflow management
systems (Snakemake, Nextflow), and post-processing tools (ParaView, CDO).

Each module includes the learning outcomes, a command cheatsheet, and a quiz with
instant feedback and explanations.
